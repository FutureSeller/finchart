The declarative lane reaches what used to need a `useChartPlot` + `useEffect` shim. `<ChartContainer options>` takes the plot options that have no prop of their own (`padding`, `resizablePanes`, `shiftVisibleRangeOnNewBar`, `axisDrag`, `rightOffset`, `minBarSpacing`, `maxBarSpacing`); a key that is dropped reverts to what the plot was built with, and it is applied before the first series registers, so `rightOffset` shapes the first fit whatever the JSX order. `<ChartContainer followTheme>` wires `observeTheme` to the container and redraws the canvas when the theme moves. `<ChartPane>` takes `autoScale`, `invert` and `yScale` — the scale as a factory called at acquisition, like `deps.mainPaneYScale`, and again whenever its identity changes; on the main pane the scale it replaced comes back when the pane goes — and applies only the field whose prop changed, so a `minHeight` change no longer undoes a divider drag. `usePlugin`'s `install` may return `null` for "not yet", which is how an indicator waits for the series handle it reads (a handle is a `Source`).

`<ChartLine>` and `<ChartCandles>` take `style` in the imperative lane's override shape — the same `LineSeriesStyleOverrides` / `CandleSeriesStyleOverrides` that `lineSeries(style)` and `candleSeries(style)` take. The flat mirror props (`color`, `width`, `pointRadius`, `pointColor`; `up`, `down`, `wickWidth`, `bodyRatio`) are gone: a mirror has to be kept in step by hand and this one already lagged (`dashArray` had no prop). `line.color` still doubles as the legend swatch.
