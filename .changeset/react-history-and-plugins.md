React gets the pieces a real trading screen was hand-rolling around the chart. `useInfiniteHistory` holds paged history as React state together with the loader's place — the first bar held, the paging token, the end — and `<InfiniteHistory history>` inside the chart pages into it. A load is `history.reset(bars, { next, fetchPage })` (or `{ fetch }` by time): the fetch comes with the load, so no later render pairs its token with another symbol's API, and an edit (`setData(update, load?)`) is for one load's bars — the one it names, or the one on screen — so a tick for a symbol being left never lands on the next one's; a chart remounted under a `key` resumes instead of asking for the first page again, a page landing for a load `reset` replaced is dropped, and `status` is state. `<Plugin install deps onApi>` puts a tool on the chart as a child and hands its api to the parent (after commit, and `null` to the same callback before it's disposed). `<ChartPane valueDomain={[min, max]}>` declares a fixed value range — an oscillator pane — applied when its two numbers change, and `<ChartPane yScale>` now follows its prop: a new factory (its identity is the change — pin it) installs its scale in place, keeping the pane, its series and its height, and removing it puts back a linear scale (on the main pane, the one it replaced). In core, a loader reads `cursor()` — in cursor mode the token the next fetch would take, moved by an empty page too; `null` in x mode — typed on what `infiniteHistory` now returns, `CursorHistoryLoader<C>` (an x-mode loader is a `CursorHistoryLoader<never>`); the `HistoryLoader` interface is unchanged, but a type derived from the function (`ReturnType<typeof infiniteHistory>`) now includes `cursor()` — a hand-written stand-in for it implements `cursor()` or is typed as `HistoryLoader`. `<ChartPane valueDomain>` wins over `autoScale` while it's set; once removed, the pane does what `autoScale` says.
